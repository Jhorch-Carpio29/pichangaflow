# apps/web: front (Next.js)

| Carpeta | Qué va aquí |
|---|---|
| `src/app/` | Rutas y páginas |
| `src/components/ui/` | Componentes base reutilizables |
| `src/components/panel/` | Plantilla de panel: menú lateral y barra superior |
| `src/components/marca/` | Logo y pantallas de mensaje |
| `src/components/portada/` | Fondo y mapa animados de la página de inicio |
| `src/config/menus.ts` | Opciones del menú de cada rol |
| `src/lib/` | Utilidades y cliente del back |

Los colores, letras y sombras se definen solo en `src/app/globals.css`. Ninguna pantalla usa colores sueltos.
