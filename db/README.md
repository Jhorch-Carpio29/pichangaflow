# db

Base de datos en Neon, una por empresa más una de control.

| Carpeta | Contenido |
|---|---|
| `migrations/control/` | BD de control: empresas, planes y suscripciones |
| `migrations/tenant/` | BD de cada empresa: usuarios, canchas, reservas, ventas, cocheras |
| `seeds/` | Datos de ejemplo para desarrollo y pruebas |
